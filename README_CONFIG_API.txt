F.R.I.D.A.Y. — configuração da API

- A Dashboard não recebeu botão de cadastro.
- O botão "⚙ CADASTRAR API" aparece somente no Chat e no Áudio, abaixo do botão de voltar à Dashboard.
- A configuração salva no navegador tem prioridade sobre o config.env.
- Não incluí a sua config.env real neste ZIP para não expor sua API Key.
- Se quiser usar config.env, copie config.env.example para config.env e preencha os valores.
